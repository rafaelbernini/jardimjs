    Boas-vindas ao JardimJS!

    Seu objetivo é levar o robô até o portal escrevendo JavaScript de verdade. Cada missão ensina um conceito novo.

    1. Leia o objetivo e observe o tabuleiro.
    2. Digite comandos como direita(); no editor.
    3. Clique em Executar código para acompanhar os movimentos.
    4. Se errar, veja a mensagem, ajuste o código e tente outra vez.
    5. Complete a missão e avance. Sua conquista fica salva localmente.

    É necessário informar nome e turma antes de começar. O código é executado em um Web Worker com limite de tempo. O progresso fica neste navegador. Conclua cada fase para liberar a próxima e baixe o JSON para entregar ao professor.
