# JardimJS 4.1.0 — versão completa

- Interface ilustrada com SVG, mascote, portais e quatro mundos.
- 24 fases interativas, Web Worker, pistas, registro de métricas e progresso.
- API JavaScript, SQLite local Node 22 e SQLite remoto Turso para Vercel.
- Sessão do aluno e envio definitivo com comprovante JSON e relatório PDF via impressão.
- Painel administrativo para consulta, exportação CSV, exclusão e avaliação individual.
- Novo na versão 4.1: tabela `assessments`, lançamento de nota, devolutiva e exportação CSV enriquecida.
- Materiais de professor e enunciado A4 para o portal escolar.

**Validações:** `npm run check` passou, teste visual do painel com nota passou, simulação de todas as 24 fases existente. Instalação real em Turso/Vercel não executada porque não foram fornecidas credenciais.
